# v1.1.0 – Independent external validation update

This release extends the reproducibility materials for the cross-disease endometrial atlas with independent external validation of the frozen analytical timing coordinate.

Added:

- validation source data for GSE234368, GSE98386, GSE180485 and GSE144895;
- source data supporting Figure 7 and Supplementary Figures S22–S25;
- Supplementary Table S15 source data;
- frozen-gene coverage and validation provenance records;
- lightweight scripts reconstructing the primary point/rank statistics from the released timing-score tables.

The core atlas analyses and previously released source materials remain unchanged.

The repository remains a selected source-table reproducibility package and does not mirror raw GEO expression matrices or provide a complete raw-data-to-atlas reconstruction workflow.
