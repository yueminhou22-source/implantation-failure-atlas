# Selected source-table reproducibility package

This package contains selected source tables and selected scripts for formal figure/table rebuilds used in the submission. It does not include raw GEO downloads, complete large expression matrices, all single-cell integration objects, or a complete end-to-end atlas reconstruction. The package is intended for transparent inspection and selected source-table regeneration within the documented scope.

Paths and user-specific identifiers have been removed from public text. The package does not claim full raw-data replay or a complete preprocessing environment.


## Final Supplementary numbering crosswalk

Historical filenames are retained for script lineage and do not represent public Supplementary Table numbers. Table_S20 module-membership files map to final Supplementary Table S11; Table_S21 HECA remapping files map to final Supplementary Table S12; Table_S22 HECA sensitivity files map to final Supplementary Table S13. This remains a selected source-table reproducibility package, not a complete raw-GEO-to-atlas replay; complete large expression matrices, all single-cell objects and a full end-to-end preprocessing environment are not included.
